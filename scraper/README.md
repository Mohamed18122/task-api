# The Polite Scraper

## Target classification

**Target:** Books to Scrape — https://books.toscrape.com/

Books to Scrape is a public practice sandbox built for learning web scraping.

**Scope:** The scraper will process only the first 3 catalogue pages and discover the 60 book pages linked from them.

**Data collected:** Book title, product URL, price, availability, rating, description, source catalogue page, and fetch timestamp.

**Robots check:** `https://books.toscrape.com/robots.txt` returned `404 Not Found`, so no robots file was found.

This target is appropriate because Books to Scrape is a practice sandbox intended for scraping exercises.

I will not reuse this code on another site without checking its rules and terms first.
